Dashboard

Dashboard igaragaza: Total Students Total Money Collected Students with Debt Current Term Ibi bifasha kumenya uko amafaranga yishuri ahagaze.

Kongera Umunyeshuri (Add Student)

Kwishyura Amafaranga (Record Payment) Kwandika amafaranga yishyuwe: Hitamo student muri table Kanda PAYMENT Andika amafaranga yishyuwe Kanda SAVE System ihita ibara: Remaining Balance = Total Fees – Paid

Kureba Ideni (Debt)

System ihita igaragaza: amafaranga yishyuwe amafaranga asigaye Abanyeshuri bafite ideni bagaragara muri: Outstanding Balance

  • Search Student Ushobora gushaka umunyeshuri ukoresheje: Student ID Name Class Andika muri Search Box hanyuma system ihite imushaka.
  • Sorting Table Columns zose zishobora gusortwa. Urugero: sort by Name sort by Class sort by Debt Kanda ku heading ya column.
  • Advance Term Iyi function ikoreshwa: kwimura abanyeshuri mu gihembwe gikurikira Steps: Kanda Advance Term Reba preview y’abafite ideni Kanda Advance System izakora: copy students mu term nshya carry forward debt reset payments
  • Reports Report system ikoreshwa gukora: debt reports student payment reports Steps: Kanda Report Manager Hitamo: Export Selected Student cyangwa Export All Students Files zizabikwa nka: Debt_Report_Name.txt
